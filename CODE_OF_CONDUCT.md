# Code of Conduct

Plynte Labs is an open-source space for learning, building, and collaboration. We expect direct, respectful, technically grounded communication.

Plynte Labs es un espacio open-source para aprender, construir y colaborar. Esperamos comunicación directa, respetuosa y técnicamente fundamentada.

## Expected behavior

- Be respectful and constructive.
- Critique ideas, code, and tradeoffs — not people.
- Give context when disagreeing.
- Assume good intent, but verify technical claims.
- Help newcomers learn the fundamentals, not just copy solutions.

## Unacceptable behavior

- Harassment, insults, discrimination, or threats.
- Publicly sharing private information.
- Repeated bad-faith arguments or spam.
- Dismissing maintainers' review boundaries or project scope.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants when behavior harms the project or community.
