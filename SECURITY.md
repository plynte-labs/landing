# Security Policy

## Supported projects

Security reports are accepted for public Plynte Labs repositories that are actively maintained. Experimental or coming-soon projects may not have a stable security surface yet.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

Email: gitrafuh@gmail.com

Include:

- Repository and affected version or commit.
- Clear reproduction steps.
- Expected impact.
- Any proof-of-concept details that help verify the issue safely.

We will acknowledge valid reports as soon as possible and coordinate a fix before public disclosure.

## Política de seguridad

No abras issues públicos para vulnerabilidades. Enviá el reporte por email con repositorio afectado, pasos de reproducción, impacto esperado y detalles suficientes para verificarlo de forma segura.
