**WARNING**:
- Sitemap includes a **duplicate `<url>` entry** for `/` (two identical `<url>` blocks in `dist/sitemap.xml`). This comes from `vite-plugin-sitemap` auto-detecting `index.html` AND processing `dynamicRoutes: ['/']` — both resolve to the same path. Fix: remove `dynamicRoutes: ['/']` since the plugin already discovers `/` from the HTML output. Not a spec failure (the `<url>` content is correct), but wastes 306 bytes and may confuse crawlers.
- Scenario title bug: "Build succeeds without sitemap plugin" should be "Build fails without sitemap plugin" per the THEN clause body. Task 3.5 marks this for correction. This is a spec-editing issue, not an implementation issue.

**SUGGESTION**:
